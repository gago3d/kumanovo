# Куманово 3D — Kumanovski Stan

Жива 3D мапа на општина Куманово. Јавни огласи, агенти што ги проверуваат, улици од OpenStreetMap.

## И тука и таму

| Каде | Што |
|---|---|
| Овој Grok разговор | Жив преглед — останува вклучен |
| [gago3d.github.io](https://gago3d.github.io/) | Јавен сајт, 24/7, без Grok |
| Овој репо | Целиот код за друг Grok / друг компјутер |

## Отвори во нов Grok Build

Залепи го ова во нов Grok разговор:

```
Отвори го репото https://github.com/gago3d/kumanovo
инсталирај и пушти npm run dev на 0.0.0.0:8080.
Ова е Куманово 3D — мапа + јавни огласи.
Не го исклучувај додека не кажам „исклучи“.
```

## Локално

```
npm install
npm run dev
```

Отвори http://127.0.0.1:8080/

Јавен билд: `npm run build:pages` → папката `pages-dist` оди на GitHub Pages.

Бесплатни извори (не се тргаат): OpenFreeMap, Photon, Nominatim, OSRM, Open-Meteo, OSM, Esri satellite, Pazar3 јавни огласи.
